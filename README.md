
# Raspberry Pi/ Linux
ดาวห์โหลดและติดตั้ง
```
sudo rm -f -r  ~/bosshub-vnc
git clone https://github.com/x-bosshub/bosshub-vnc.git
chmod +x ~/bosshub-vnc/install.sh
sudo bash ~/bosshub-vnc/install.sh
```
# ลบการติเตั่ง
```
sudo bash ~/bosshub-vnc/remove.sh
sudo rm -f -r ~/bosshub-vnc
```
